== Description ==

Hariko Business is a child theme that uses the Hariko theme as its parent. Slider content requires the WP Swiper plugin to be installed and activated.

== Changelog ==
= 1.0.6 =
* Updated for Hariko 1.0.13.
* Migrated font size and spacing presets to the parent theme's numeric slugs (2-xl to 6-xl).
* Loaded the parent theme stylesheet (hariko-theme) before the child theme stylesheet.
* Added the sans-serif and serif font family aliases used by the parent theme.
* Removed the empty sidebar template part and used the parent theme's sidebar.
* Rebuilt the index template that referenced a missing pattern.
* Fixed editor style loading and registered editor-style.css.

= 1.0.5 =
* Updated theme.json for WordPress 7.1 compatibility.
* Replaced the bundled TGMPA library with a built-in WP Swiper installation, activation, and update notice.
* Fixed stylesheet loading and the skip-link target.

= 1.0.4 =
* Parent theme update hooks

= 1.0.3 =
* Fixed issue with page-fullwidth template not loading.

= 1.0.2 =
* Fixed issue with custom templates not loading

= 1.0.1 =
* Parent theme update hooks

= 1.0 =
* Initial release
